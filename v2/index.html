01 — The hide

One skin, two shoes.

Vegetable-tanned leather, cut as a pair so the colour matches. The upper is still quiet here. The embroidery comes later.

02 — The last

Pulled to the foot.

The upper is drawn over a men's Jaipur last and left to settle. This is the slow part. A size is a shape, not a number on a box.

03 — The thread

Gold, where it belongs.

A buta on the vamp. Heavier on the nagra, quieter on the black pair. The khussa can leave this step almost silent.

04 — The sole

Stitched, then checked.

A leather sole, sewn through, then looked at as a pair. It leaves Jaipur insured, with a packing list if the order is a size run.
